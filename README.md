## Detection, Distance Estimation and Automatic Target Lock using YOLO and DETR

An AI-powered drone surveillance framework integrating YOLO and Deformable DETR for real-time object detection, target tracking, distance estimation, and automatic target locking.

### Features

- Real-time drone surveillance
- YOLO-based object detection
- Deformable DETR detection pipeline
- Automatic target locking
- Distance estimation
- Zero-shot drone detection
- Video inference pipeline
- Military and defense-oriented applications
